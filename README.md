# Localist

Static frontend prototype. No build step.

## Structure
```
index.html              Page markup
assets/css/styles.css   Styles
assets/js/app.js        Pages, data and interactions
```

## Run locally
Open `index.html` in a browser.

## Deploy on Vercel
1. Upload this folder to a GitHub repository (all files at the repository root).
2. On vercel.com: Add New → Project → Import the repository.
3. Framework Preset: Other. Leave Build Command and Output Directory empty.
4. Click Deploy.
